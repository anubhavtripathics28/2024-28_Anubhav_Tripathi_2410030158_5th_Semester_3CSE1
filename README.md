## About the Project

Students often have items they no longer need — books, notes, gadgets — while other students want the same items at a lower price. This usually happens through messy WhatsApp groups or notice boards. **Campus Exchange** solves this by giving a campus a simple, dedicated website where students can post items and easily find what they need.

**Tech Stack:** HTML, CSS, JavaScript, Java, Spring Boot, MySQL

**Features:**
- Add a new item with name, description, and price
- View all items listed by other students
- Data saved permanently in a MySQL database
